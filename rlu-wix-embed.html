RLU GUIDELINE

แนวทางการตรวจทางห้องปฏิบัติการทางการแพทย์อย่างสมเหตุผล

การตรวจทางห้องปฏิบัติการที่มากเกินไปอาจนำไปสู่การสิ้นเปลืองที่ไม่จำเป็น ในขณะที่การตรวจที่ น้อยเกินไปอาจนำไปสู่การวินิจฉัยที่ผิดพลาดหรือเกิดผลเสียหายต่อการรักษาผู้ป่วย การศึกษาของต่างประเทศพบว่า มีการสั่งตรวจที่น้อยเกินไป (Underutilization) ประมาณ 45% และมีการสั่งตรวจที่มากเกินไป (Overutilization) ประมาณ 20% ดังนั้นหากนำเอา RLU มาประยุกต์ใช้ในระบบบริการสุขภาพของประเทศที่มีค่าใช้จ่ายทางห้องปฏิบัติการเฉพาะในส่วนของกระทรวงสาธารณสุขปีละประมาณ 15,000 ล้านบาท อาจทำให้ลดค่าใช้จ่ายในส่วนนี้ลงไม่น้อยกว่า 3,000 ล้านบาทต่อปี

แก้ไข Guideline





📘 คู่มือการใช้งานระบบ RLU Digital Intelligence Website

1. บทนำระบบ

ระบบ RLU Digital Intelligence Website เป็นแพลตฟอร์มที่ใช้สำหรับรวบรวมข้อมูลเกี่ยวกับ RLU ของโรงพยาบาลพระปกเกล้าและใช้สำหรับการติดตามตัวชี้วัดของ RLU โดยมีการเชื่อมโยงข้อมูลจากแหล่งข้อมูลภายนอก คือ ระบบคลังข้อมูลด้านการแพทย์และสุขภาพ (HDC) และโปรแกรม S2G for blood safety เพื่อแสดงผลในรูปแบบ Dashboard แบบ Real-time

2. สิทธิ์ผู้ใช้งาน

  • Admin: สามารถอัปโหลด แก้ไข และจัดการข้อมูลทั้งหมดในระบบ
  • User: สามารถเข้าดูข้อมูล Dashboard RLU Guideline และเอกสารสำคัญได้

3. โครงสร้างระบบ

  • Dashboard KPI แสดงผลรวมและรายตัวชี้วัด
  • RLU Pyramid แสดงบันไดสี่ขั้นของการจัดทำ RLU
  • Document Management สำหรับจัดเก็บเอกสาร
  • Feature Section สำหรับแสดงกิจกรรมต่างของ RLU

4. การใช้งานเมนูหลัก

📊 ตัวชี้วัด (KPI)

  • ALL: แสดงตัวชี้วัดทั้งหมดในรูปแบบกราฟ
  • Single: แสดงข้อมูลรายตัวชี้วัด
  • Custom KPI: แสดงแนวโน้มข้อมูลรายเดือน

📂 เอกสารสำคัญ

  • อัปโหลดและจัดเก็บเอกสารผ่าน Google Drive

5. การอัปโหลดข้อมูล KPI

  • ใช้สำหรับตัวชี้วัดประเภทที่ต้องตรวจอย่างน้อยปีละครั้ง
  • รองรับไฟล์ CSV (HbA1c / LDL-Cholesterol / Creatinine)
  • ระบบจะทำการแทนที่ข้อมูลเดิมโดยอัตโนมัติ
  • โดย Admin จะอัปโหลดทุกวันศุกร์ของสัปดาห์เพื่อให้ข้อมูลเป็นปัจจุบันมากที่สุด

6. หลักเกณฑ์การประเมิน

  • ร้อยละของผู้ป่วยโรคเบาหวานได้รับการตรวจ HbA1c ซ้ำภายใน 90 วัน < 5%
  • ร้อยละของผู้ป่วยโรคเบาหวานได้รับการตรวจ LDL-Cholesterol ซ้ำภายใน 90 วัน < 5%
  • ร้อยละของผู้มารับบริการได้รับการตรวจ Total Cholesterol ซ้ำภายใน 90 วัน < 5%
  • ร้อยละของผู้มารับบริการได้รับการตรวจ Triglycerides ซ้ำภายใน 90 วัน < 5%
  • ร้อยละผู้ป่วยโรคเบาหวานได้รับการตรวจ HbA1c อย่างน้อยปีละ 1 ครั้ง > 70%
  • ร้อยละของผู้ป่วยโรคเบาหวานได้รับการตรวจ LDL-Cholesterol อย่างน้อยปีละ 1 ครั้ง > 70%
  • ร้อยละของผู้ป่วยโรคเบาหวานได้รับการตรวจ Creatinine อย่างน้อยปีละ 1 ครั้ง target > 70%
  • อัตราการรายงานผลตรวจได้ทันตามกำหนด > 99%
  • ลดค่าใช้จ่าย < 10%
  • C/T Ratio < 2%

7. การเชื่อมโยงข้อมูล

  • เชื่อมต่อ API จาก HDC กระทรวงสาธารณสุข
  • เชื่อมต่อ API จาก โปรแกรม S2G blood safty ของโรงพยาบาลพระปกเกล้า
  • รองรับข้อมูลจากไฟล์ CSV ภายในหน่วยงาน
  • ผสานข้อมูลเพื่อแสดงผลใน Dashboard

8. ระบบแจ้งเตือน

  • ส่งสรุป KPI ผ่าน LINE Group
  • แสดงสถานะผ่าน / ไม่ผ่าน ในตัวชี้วัดหลักของ RLU
  • แสดง ward 7 อันดับที่ C:T Ratio มากกว่า 2 คำนวณเฉพาะ RBC และเฉพาะ ward ที่มีการใช้เลือดจริง
  • สามารถกดเข้าดู Dashboard ได้ทันที

9. ข้อควรระวัง

  • การอัปโหลดข้อมูลใหม่จะทับข้อมูลเดิม
  • ควรตรวจสอบไฟล์ก่อนนำเข้า
  • หากข้อมูลไม่แสดงให้รีเฟรชหน้าเว็บหรือติดต่อผู้ดูแลเว็บไซด์
